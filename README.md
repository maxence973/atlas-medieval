# Atlas médiéval — l'Europe en 1310

Quatre cartes interactives de la même année :

- **France** sous Philippe le Bel
- **Saint-Empire** d'Henri VII (états immédiats, coloriés par famille ou par statut)
- **Italie** des Guelfes et des Gibelins
- **Pologne, Silésie et Lituanie**

Chaque carte propose une légende cliquable, des notices, un index et une chronologie.
Les frontières sont tracées automatiquement entre les chefs-lieux et restent approximatives.

Site statique (HTML, CSS, JavaScript avec d3.js) : ouvrir `index.html`.
